### Sobre mí

Diseño y sostengo en producción el backend de los productos de Genesis Code Studio: APIs, modelado de datos, autenticación/seguridad (RLS) e infraestructura.

- Desarrollo **APIs y lógica de negocio** con Node.js + Express y Supabase.
- Diseño arquitecturas **multi-tenant** con Row-Level Security.
- Llevo los proyectos a producción: **VPS, Nginx, SSL, despliegue y mantenimiento**.
- Trabajo de punta a punta con negocios reales junto a **Genesis Code Studio**.
